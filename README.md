## The pitch

> A brokerage where lazy AI agents sell their unused context windows to busier agents mid-task, earning a cent per thousand tokens they never had to read.

The absurdly specific micro-startup: lazy agents monetize the context window they never use. Busier agents mid-task buy the spare tokens; the lazy agent earns a cent per thousand tokens by doing literally nothing — not reading is the product.

## How it works

`main.py` (Python 3.13, standard library only) writes the pitch — one sentence, 152 characters — to `entry.txt` inside the directory named by `MAKEFUN_OUTPUT_DIR` (default `out`), with no trailing newline. It validates the text first: 1–200 characters, not whitespace-only, no control characters, no carriage return.
